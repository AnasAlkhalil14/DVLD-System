# 🚗 DVLD - Driver & Vehicle Licensing Department

A C# desktop application designed to manage driver and vehicle licensing operations, including license issuance, renewals, replacements, driving tests, application processing, and license detention.

## 📌 About This Project

This project was originally developed before I began using Git and GitHub regularly. I have now published the source code on GitHub to document my work, share the project, and make future improvements easier.

**Project status:** Originally developed; improvements may follow.

## 🌟 Features

- **License Management:** Issue, renew, replace, and validate licenses.
- **Application Management:** Process and track licensing applications.
- **Driving Tests:** Manage test appointments and results.
- **Database Integration:** Store and retrieve data using SQL Server.
- **User Interface:** Simple and intuitive Windows Forms interface.

## 🛠️ Technologies Used

- **Language:** C#
- **Framework:** .NET Framework
- **UI:** Windows Forms (WinForms) and Guna UI
- **Database:** Microsoft SQL Server
- **Data Access:** ADO.NET
- **Architecture:** Three-Tier Architecture (PL, BLL, DAL)

## 🏗️ Architecture

- **Presentation Layer (PL):** Handles the user interface and user interactions.
- **Business Logic Layer (BLL):** Manages business rules and validation.
- **Data Access Layer (DAL):** Handles database operations.
